Integraciones: antispam, avisos y API REST

1 de agosto de 2026

Chat CRM no pretende sustituir a todo lo que ya usa el equipo: se conecta con ello. Estas son las integraciones que trae de serie.

Antispam

reCAPTCHA protege los formularios de spam y bots. Cloudflare Turnstile hace lo mismo sin fricción para el usuario, que ni se entera de que está siendo verificado.

Avisos

Telegram manda avisos instantáneos de cada evento nuevo, y Twilio envía alertas por SMS para lo que no puede esperar a que alguien mire el panel.

Datos y desarrollo a medida

  • Google Sheets, para importar y exportar los datos del equipo.
  • API REST y webhooks, para cualquier integración que no venga de fábrica.

Con esto se cierran los nueve módulos de la plataforma: bandeja compartida, canales, widget, chatbots, IA, base de conocimiento, tickets, campañas de WhatsApp e integraciones.
